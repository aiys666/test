# 异常处理速查

> 处理具体异常场景时查阅。先读 SKILL.md 根因下钻（Phase 3）确定方向，再到此表找操作路径。

| 异常场景 | 立即检查项 | 操作路径 |
|---------|-----------|---------|
| **CPS 飙升 > 目标 30%** | ① 频次过高？② CPM 上升？③ 回传故障？④ 竞品涌入？ | ① 降出价 10% → ② 换素材 → ③ 排查回传 |
| **预算花不出去** | ① 出价过低？② 受众过窄？③ Learn Limited？ | ① 提高出价 10% → ② 放宽受众 → ③ 检查素材 |
| **放量掉量** | ① 素材疲劳（CTR↓）？② 竞品大促？③ 流量波动？ | ① 换素材 → ② 增加受众 → ③ 加预算 |
| **FPD 上升** | ① 渠道结构变化？② 新素材吸引高风险用户？③ 风控调整？ | ① 排除高风险渠道 → ② 收紧出价 → ③ 与风控对齐 |
| **数据回传不匹配** | ① CAPI/SDK 配置？② 三方归因对比？③ 事件映射？ | ① 检查 MMM → ② 确认转化窗口设置 |
| **新渠道测试失败** | ① 给够学习预算？② 素材适配平台？③ 出价合理？ | ① 给足 50 转化预算 → ② 换平台适配素材 → ③ 调整出价 |
| **CPS↑ + Grade1-2%↑ + 消耗↓** | ① 风控通过率变化？② 进件量正常？ | ⚠️ 不调投放，与风控对齐，重新校准 CPS 目标（见 learned-patterns.md #001） |
