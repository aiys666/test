## #001 CPS上升归因：区分风控与投放问题

> **发现日期**：2026-06-02
> **触发场景**：印尼市场 CPS $18→$24，用户给了两层数据（业务漏斗+广告日报）要求分析根因
> **用户确认**：✅ "这条分析思路很正确"

### 案例摘要

用户提供 (1) 业务漏斗数据（进件、风险通过率、用信率）、(2) 广告投放日报（消耗、安装、注册、进件、放款、CPS 分日）。
CPS 从 $15.71 上升到 $16.79（+7%），实际根因不在投放端。

### 分析步骤

**Step 1 — MECE 拆解 CPS 分子分母**
CPS = 消耗 / 放款数
→ 先判断是分子(消耗)问题还是分母(放款数)问题
→ 计算日均变化率：消耗 -35%，放款数 -39%
→ 放款数下降速度**快于**消耗下降速度 → 分母驱动型 CPS 上升

**Step 2 — 对分母(放款数)做下钻**
放款数 = 进件量 × 风险通过率 × 用信率
→ 逐个对比各环节变化率
→ **找到拐点指标**：风险通过率从 13.7% 骤降到 8.6%（-37%）
→ 进件量仅 -10%，用信率变化不大 → 根因锁定在风险通过率

**Step 3 — 去广告侧数据佐证**
广告侧数据显示：
- 消耗在主动下降（$34K→$22K），不是成本端失控
- 安装/注册/进件流量正常，只是放款端断崖
- Grade1-2 占比反升（19%→30%）→ 风控筛掉了低质用户

**Step 4 — 最终诊断**
→ 结论：CPS 上升不是投放效率问题，而是风险策略收紧导致的分母收缩
→ 策略建议：不调投放，与风控对齐，重新校准 CPS 目标

### 关键启示

1. **CPS 上升不一定是投放问题** — 可能是风控、产品、市场原因。先做 MECE 拆解再下结论。
2. **广告数据 + 业务数据要交叉验证** — 只看广告数据会误判为"投放效率下降"。
3. **关注 Grade1-2 占比的同步变化** — 如果 CPS 上升同时 Grade1-2 占比也上升，通常是"被动提纯"现象。
4. **消耗下降如果是主动行为就是合理的** — 消耗下降 + 放款数更大幅度下降 = 被动 CPS 上升。
5. **"量降质升"是风控收紧的典型信号** — 放款量下降 + Grade1-2 占比上升 + FPD 可能下降。
6. **分析必须给出"不是投放问题"的勇气** — 当根因是风控/产品问题时，不要强行输出投放优化建议。
7. **CPS 目标应该随风险策略动态调整** — 风控收紧后，原来的 CPS 目标已经失效，需要重新校准。

### 决策规则

- IF CPS↑ AND 消耗↓ AND 放款数↓↓ → THEN 优先怀疑分母端问题，非成本端问题
- IF CPS↑ AND Grade1-2%↑ → THEN 优先怀疑风控收紧（"被动提纯"信号）
- IF 进件量正常 AND 风险通过率↓ > 20% → THEN 根因锁定在风控，非投放端
- IF 确认风控收紧 → THEN 不调投放策略，建议与风控对齐 + 重新校准 CPS 目标
- IF 用户同时给广告数据 + 业务数据 → THEN 必须做交叉验证，不能只看广告端

### 适用场景关键词
CPS涨了、成本上升、效率下降、放款少了、通过率降了、量降质升、消耗降了
