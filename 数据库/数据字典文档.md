# 金融风控数据集市 - 数据字典文档

## 文档信息
- **数据库名称**: YSProd
- **数据库类型**: MySQL
- **设计标准**: Kimball维度建模方法论
- **文档生成日期**: 2026-05-03
- **版本**: v1.0

---

## 一、数据库架构概述

本数据集市采用星型模型（Star Schema）架构，包含以下类型的表：

### 1.1 维度表 (Dimension Tables)
维度表用于存储描述性信息，作为分析的角度和上下文。

| 表名 | 中文名称 | 说明 |
|------|---------|------|
| dim_time | 时间维度表 | 记录日期时间维度信息 |
| dim_product | 产品维度表 | 记录产品维度信息 |
| dim_customer | 客户维度表 | 记录客户维度信息 |
| dim_location | 地域维度表 | 记录地域维度信息 |
| dim_organization | 机构维度表 | 记录组织机构维度信息 |

### 1.2 事实表 (Fact Tables)
事实表用于存储业务过程的具体度量数据。

| 表名 | 中文名称 | 说明 |
|------|---------|------|
| fct_loan_application | 贷款申请事实表 | 记录贷款申请业务过程 |
| fct_loan_disbursement | 贷款发放事实表 | 记录贷款发放业务过程 |

## 三、表关系说明

### 3.1 ER图关系描述

```
dim_time (time_id)
    ↑
    │ time_id
    │
fct_loan_application ←───────────── dim_customer (customer_id)
    │  (application_id)                   │
    │                                      │
    ↓                                      │
fct_loan_disbursement ←─ dim_product (product_id)
    │  (disbursement_id)          ↑
    │                             │
    └────── dim_organization (org_id)
               │
               ↑
         dim_location (location_id)
```

### 3.2 关系说明

1. **dim_time**: 时间维度，所有事实表通过time_id关联
2. **dim_customer**: 客户维度，通过customer_id与事实表关联
3. **dim_product**: 产品维度，通过product_id与事实表关联
4. **dim_organization**: 机构维度，通过org_id与事实表关联
5. **dim_location**: 地域维度，通过location_id与事实表关联

## 四、查询示例

### 4.1 按产品统计贷款申请情况

```sql
SELECT
    p.product_name,
    COUNT(*) as application_count,
    SUM(CASE WHEN a.application_status = 'approved' THEN 1 ELSE 0 END) as approved_count,
    ROUND(SUM(CASE WHEN a.application_status = 'approved' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as approval_rate,
    AVG(a.apply_amount) as avg_apply_amount
FROM fct_loan_application a
JOIN dim_product p ON a.product_id = p.product_id
GROUP BY p.product_name
ORDER BY application_count DESC;
```

### 4.2 按月统计贷款发放情况

```sql
SELECT
    t.year_num,
    t.month_num,
    COUNT(*) as disbursement_count,
    SUM(d.loan_amount) as total_loan_amount,
    AVG(d.interest_rate) as avg_interest_rate,
    SUM(d.haircut_amount) as total_haircut_amount
FROM fct_loan_disbursement d
JOIN dim_time t ON d.time_id = t.time_id
GROUP BY t.year_num, t.month_num
ORDER BY t.year_num, t.month_num;
```

### 4.3 按地域统计客户分布

```sql
SELECT
    l.province,
    l.city,
    COUNT(*) as customer_count,
    AVG(c.credit_score) as avg_credit_score,
    SUM(CASE WHEN c.risk_level = 'Low' THEN 1 ELSE 0 END) as low_risk_count,
    SUM(CASE WHEN c.risk_level = 'Medium' THEN 1 ELSE 0 END) as medium_risk_count,
    SUM(CASE WHEN c.risk_level = 'High' THEN 1 ELSE 0 END) as high_risk_count
FROM dim_customer c
JOIN dim_location l ON c.city = l.city
GROUP BY l.province, l.city
ORDER BY customer_count DESC;
```
