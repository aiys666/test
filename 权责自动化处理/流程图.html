📋 使用说明

命令 作用
python pipeline.py 一键执行所有启用的步骤 (Step1→Step5)
python pipeline.py --step 2 只执行步骤 2 (复贷预估)
python pipeline.py --steps 1,3,4 执行步骤 1,3,4 (坏账 + 权责 + 入库)
python pipeline.py --dry-run 预检查模式，验证配置不实际执行
python pipeline.py --skip-db 跳过数据库操作，只生成本地 Excel 文件
