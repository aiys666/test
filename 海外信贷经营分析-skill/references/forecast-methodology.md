# 经营预估方法论

> 月度经营计划预估的核心算法和模型原理。基于 pipeline Step2/Step3 的 Python 实现。

## 一、首贷预估

### 公式链

```
月安装量 = 日投放消耗 / CPI × 月天数
首贷进件量 = 月安装量 × 安装注册率
首贷放款笔数 = 首贷进件量 × 综合通过率 × 签名放款率
首贷放款金额 = 首贷放款笔数 × 件均
```

### 参数说明

| 参数 | config.yaml 路径 | 典型值(印尼) |
|------|-----------------|-------------|
| 日投放消耗 | `first_loan.daily_spend` | $2,200 |
| CPI | `first_loan.cpi` | $3.6 |
| 安装注册率 | `first_loan.install_register_rate` | 80% |
| 综合通过率 | `first_loan.pass_rate` | 65% |
| 签名放款率 | `first_loan.sign_loan_rate` | 95% |
| 件均(USD) | `first_loan.avg_amount` | $62 |

### 当月预估调整

当月数据按已过天数线性外推：
```
预估全月 = 当前累计 × 月总天数 / 已过天数
```

## 二、复贷 MOB 预估模型

### 核心思想

复贷用户不是凭空出现的。**每笔复贷都对应一笔过去的首贷**。
通过追踪"首贷 cohort 在各 MOB（账龄月）的复贷转化率"，我们可以：

> 未来月复贷量 = Σ(过去各月的首贷量 × 对应 MOB 的历史转化率)

### MOB (Month on Book) 定义

```
MOB = 复贷进件月 - 首贷放款月

例：用户 1月首贷，3月复贷进件 → MOB=2
```

### 转化率计算

```
MOB_k 转化率 = 复贷进件量(cohort_i, MOB=k) / 首贷放款量(cohort_i)
```

每个 MOB 取所有 cohort 的转化率，按 cohort 从新到旧排列。

### MA 平滑

| MOB | MA 方法 | 原因 |
|-----|--------|------|
| MOB=0 (当月) | 取最近 2 期 cohort 平均，跳过最新 cohort | 最新 cohort 当月未走完 |
| MOB≥1 (历史月) | 取最新 1 期 cohort 转化率 | 历史数据已完整 |
| 长尾 MOB (无数据) | 沿用前一个 MOB 的 MA 值 | 不衰减，保持合理值 |

### 分段调整系数

不同 MOB 阶段、不同贷款类型，调整系数不同：

| 分段 | MOB 范围 | 典型系数 | 含义 |
|------|---------|---------|------|
| 当月 | MOB=0 | 1.0 | 当月进件不作额外调整 |
| 短期 | MOB 1-3 | 1.0 | 短期还款后立即复贷 |
| 长期 | MOB 4-13 | 1.0 | 中长期复贷周期 |
| 超长期 | MOB 14+ | 1.0 | 长尾复贷 |

### 最终预估公式

```
预估复贷进件量(目标月, MOB_k)
  = 首贷放款量(target - k 月) × MA(MOB_k) × 调整系数(MOB_k, loan_type)
```

## 三、权责预估公式链

### 八个死数输入

| 符号 | 含义 | config.yaml 来源 |
|------|------|-----------------|
| J | 进件量（总） | `accrual_app_cnt` |
| K | 机审通过率 | `accrual_rates.{key}.K` |
| L | 确认借款率 | `accrual_rates.{key}.L` |
| M | 后置通过率 | `accrual_rates.{key}.M` |
| O | 签名放款率 | 首贷=0.97, 复贷=0.99 |
| Q | 各期限分布系数 | `accrual_q_dist` |
| S | 件均(万IDR) | `accrual_rates.{key}.S` |
| V | T30坏账率 | `accrual_rates.{key}.V` |

### 七步公式链

```
Step1: N = K × M                    → 机审通过×后置通过
Step2: P = L × N × O                → 确认率×机审后置×签名
Step3: R = J × P × Q                → 进件量×全流程率×Q分布 → 放款笔数
Step4: T = S / 汇率 × 10000          → 件均(万IDR→$)
Step5: U = T × R                    → 件均$×笔数 → 放款金额
Step6: W = U                        → 金额权重
Step7: X = W × V                    → 坏账$
```

### 汇总层

底部 SUMIFS 自动按月份 + 业务类型汇总：
- 坏账率 = 坏账$ / 业绩$
- 年化坏账率 = 坏账$ / 业绩$ (年化)

### Q 分布系数回退逻辑

```
Q(当月) 存在 → 使用当月值
Q(当月) 不存在 → 回退到最近有数据的月份（通常是上月）
```

## 四、模型校准

### 何时需要校准

- 每月风险团队返回新的 K/L/M/S/V 参数时
- 件均发生 10% 以上变化时
- 新产品/期限上线时
- 实际 vs 预估偏差连续 3 月 >15% 时

### 校准方法

1. **首贷预估**：对比预估 vs 实际放款笔数，调整 CPI / 通过率 / 件均
2. **复贷预估**：对比预估 vs 实际 MOB 转化率，调整 MA 窗口和调整系数
3. **权责预估**：对比 SUMIFS 输出 vs 资产底表汇总，定位偏差最大的产品×期限维度
