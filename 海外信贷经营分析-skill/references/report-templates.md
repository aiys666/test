# 报告模板

> 周报、月报、看板指标的标准输出模板。

## 一、周报模板

```markdown

> 报告期：YYYY-MM-DD ~ YYYY-MM-DD | 编制日期：YYYY-MM-DD

- 放款：X笔 / $X万 (环比±X%)
- 新客：X人首贷 / 件均$X
- 复贷：X人复贷 / 客均X笔
- T30坏账率：X% (环比±Xpp)
- 异常信号：[如有]

## 二、放款明细
| 指标 | 本周 | 上周 | 环比 |
|------|------|------|------|
| 放款笔数 | | | |
| 放款金额(USD) | | | |
| 放款人数 | | | |
| 件均(USD) | | | |
| 新客笔数 | | | |
| 复贷笔数 | | | |

## 三、进件漏斗
| 环节 | 本周 | 上周 | 变化 |
|------|------|------|------|
| 进件→确认率 | | | |
| 确认→通过率 | | | |
| 通过→放款率 | | | |
| 全流程转化率 | | | |

## 四、风险指标
| 指标 | 本周 | 上周 | 趋势 |
|------|------|------|------|
| FPD(首期逾期率) | | | |
| T30坏账率 | | | |
| Grade1-2占比 | | | |

## 五、待办事项
- [ ] 事项1
- [ ] 事项2
```

## 二、月报模板

```markdown
# 印尼业务月度经营分析报告
> 月份：YYYY-MM | 编制日期：YYYY-MM-DD

## 一、经营概览
| 指标 | 本月 | 上月 | 环比 | 预算 | 达成率 |
|------|------|------|------|------|--------|
| 放款笔数 | | | | | |
| 放款金额(USD) | | | | | |
| 收入(USD) | | | | | |
| 坏账(USD) | | | | | |
| 净收入(USD) | | | | | |
| T30坏账率 | | | | | |
| CPS | | | | | |

## 二、首贷分析
- 首贷笔数/金额/件均
- 按产品×期限分布
- 首贷转化漏斗 (安装→注册→进件→放款)

## 三、复贷分析
- 复贷笔数/金额/件均/客均笔数
- cohort复贷率 (6M/12M)
- 按MOB展开的复贷活跃度

## 四、坏账分析
- T30率趋势图
- 按产品×期限的坏账率热力图
- VINTAGE cohort坏账矩阵

## 五、下月预估
- 首贷预估
- 复贷预估
- 坏账预估
- 关键假设和风险提示
```

## 三、看板指标清单（彤姐看板对应）

基于 `彤姐看板指标数据.sql` 的输出字段：

### 放款类
- 放款人数(总/新/老)
- 放款笔数(总/新/老)
- 放款金额USD(总/新/老)
- 件均USD(总/新/老)
- 平均期限(总/新/老)

### 进件类
- 新客纯进件量/确认量/放款量
- 进件→确认率(总/新/老)
- 确认→放款率
- 机审通过率(新/老)
- 后置通过率(新/老)

### 转化类
- 注册→放款转化率(全/T0/T24h/T30d)
- 新客纯进件漏斗各环节转化率

### 风险类
- FPD逾期率(总/新/老)
- 30天逾期率(总/新/老)
- T1/T30本金逾期率(总/新/老)
- 在贷余额/在贷逾期金额
- Grade1-2占比

### cohort类
- 6月/12月复贷率(笔数/金额)
- 平均在贷金额/人
- 人均授信额度
```
